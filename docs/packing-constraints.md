# ULD 装箱边界条件与合法性规约

本文是装箱算法的约束基准。算法实现可以更换，本文规则不随实现变化。任何放置方案必须先满足这里的全部硬规则，再谈装载率。

确认日期：2026-06-10。

## 坐标与几何模型

```text
x = ULD 长度方向
y = 截面宽度方向
z = 高度方向
```

ULD 是 y-z 截面多边形沿 x 方向挤出的柱体。截面多边形至少 3 个点。

截面多边形仅支持凸多边形。输入校验应拒绝凹多边形，几何检验逻辑只需对凸多边形保证正确。

箱子是轴对齐长方体。坐标为连续浮点值，不做网格量化。

## 硬性合法规则

任何箱子放置必须同时满足以下全部条件。

### 1. 边界约束

```text
x ≥ 0, y ≥ 0, z ≥ 0
x + length ≤ uld.length
箱子的 y-z 投影矩形完全位于截面多边形内
```

凸多边形前提下，矩形 4 个角点都在多边形内即等价于整个矩形在多边形内。

### 2. 不重叠

任意两个箱子的内部体积不得相交。贴面接触（共享面、边、点）允许。

### 3. 旋转限制

```text
rotatable = false：保持输入方向，不做任何旋转
rotatable = true：仅允许长宽互换（绕 z 轴水平旋转 90°）
高度方向永远保持输入值，不侧翻、不倒置
```

这是业务约束，不是实现限制。放开全 6 朝向需要业务方重新确认。

### 4. 底面支撑

```text
z = 0：着地，视为全支撑
z > 0：底面被下方箱子顶面覆盖的面积比例必须达到最低支撑率
```

最低支撑率按搜索模式取值：

```text
fast / balanced：0.8
high_utilization：0.7
```

只有顶面高度恰好等于当前箱子底面 z 的箱子才算支撑，接触判定容差 1e-9。不同高度、未接触箱底的箱子不计入支撑面积。

## 范围外约束

以下约束明确不在当前建模范围内，算法和数据模型都不为其预留逻辑：

```text
重量、ULD 载重上限
箱子承重与堆叠强度（重不压轻）
重心平衡
装卸顺序与可达性
易碎品、特殊方向标志
```

## 输入约定

```text
box.quantity ≥ 0
container.quantity ≥ 1（默认 1）
objective = maximize_volume | maximize_count
search_mode = fast | balanced | high_utilization
```

单 ULD 输入顶层为 `uld` 键，多容器输入顶层为 `containers` 键。

## 运行时间预算

以最大参照规模 20 ULD / 25 箱型 / 1000 箱为基准，单次求解的目标时间：

```text
fast：秒级（≤ 10 秒）
balanced：半分钟量级
high_utilization：分钟级（≤ 几分钟）
```

搜索预算设计（beam 宽度、重启次数、迭代轮数等）以此为上限，装载率在预算内尽量做高。

## 结果校验

求解结果必须经过独立校验函数复查上述全部硬规则。校验不通过的方案不得标记 `validation_passed = true`，违规明细写入 `validation_errors`。

校验逻辑与放置逻辑必须各自独立实现，避免同一处 bug 同时骗过两边。
